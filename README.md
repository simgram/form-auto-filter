# Form Auto Filler

Webフォームの値を入力欄ごとにローカル保存し、同じサイトの同じページでフォームが表示されたときに自動で復元する Chrome 拡張機能です。保存値の照合はラベルとURLで行います。AIや外部APIは使用しません。

## 主な機能

- 対応する入力欄の右下にある💾ボタンから、入力値を保存
- ページ表示時やフォーム項目の追加・変更時に、保存値を空欄へ復元
- オプション画面で保存データの追加・編集・削除
- 保存データは `chrome.storage.local` に保存
- Shadow DOMを使ってボタンの表示をページCSSから分離
- 外部ライブラリ、AI、外部APIは不使用

## 対応する入力欄

- `input[type="text"]`
- `input[type="tel"]`
- `input[type="email"]`
- `textarea`

パスワード欄、チェックボックス、選択欄などは対象外です。

## インストール

1. このリポジトリをローカルにダウンロードまたはクローンします。
2. Chromeで `chrome://extensions` を開きます。
3. 右上の「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を選び、このプロジェクトのフォルダーを指定します。

## 使い方

### 入力欄から保存

1. 対象ページのフォームに値を入力します。
2. 入力欄の右下に表示される💾ボタンを押します。
3. 入力欄から取得したラベル名と、現在のページのドメイン・パスを組み合わせて保存します。

同じページで同じラベルを保存すると、以前の値を更新します。

### 自動復元

ページを開くと、空欄の入力欄について、保存データのラベルとページのドメイン・パスの両方が一致する値を復元します。フォームが後からDOMに追加された場合や、項目情報が変更された場合も照合します。入力済みの欄は上書きしません。

ラベル名は、ラベルテキスト、`aria-label`、`aria-labelledby`、placeholder、name、idなどから取得します。空白や一部の記号、`必須`・`任意`の表示を除いて比較し、正規化後に完全一致した場合に復元します。

### オプション画面

拡張機能の詳細から「拡張機能のオプション」を開き、保存データを追加・編集・削除できます。手動で追加する場合は、ラベル名、対象URL、入力値を指定します。

## URLの照合ルール

照合キーは `hostname + pathname` です。たとえば次のURLは同じページとして扱います。

```text
https://example.com/booking?menu=1
https://example.com/booking?menu=2#form
```

スキーム（HTTP/HTTPS）、ポート番号、クエリパラメーター、ハッシュは照合しません。パスは完全一致で、末尾の `/` の有無は区別します。

## プライバシー

入力値とラベル名はChromeの `chrome.storage.local` に保存されます。フォーム情報や保存値を外部サーバーへ送信する機能はありません。共有端末では、保存値をオプション画面から削除してください。

## 技術情報

- Chrome Extension Manifest V3
- Vanilla JavaScript、HTML、CSS
- 主なファイル: `manifest.json`、`content.js`、`content.style.css`、`options/`
